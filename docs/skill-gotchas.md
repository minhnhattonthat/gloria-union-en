# Gotchas for the skill

One line per gotcha: the reference file it belongs in, then the fact.

- references/platform-psp.md: PGD (`\0PGD`, e.g. `INSDIR/DATA.DNS`) is not a blocker: with drm_type 1 the vkey comes from the MAC at 0x70 (amctrl `bbmac_getkey`), so no game key is needed. `tools/pgd.py` here is a ~100-line Python port; worth promoting.
- references/platform-psp.md: `cpk.py` handles only TOC CPKs; ITOC-only CPKs (no names) need id-order walking with Align padding, see `tools/itoc.py`; `unlayla` there decompresses CRILAYLA. `Entry.parse` returns nothing and `list` prints nothing on these rather than failing.
- references/setup.md: `fetch_emu.py` fails with `CERTIFICATE_VERIFY_FAILED` on stock Python for Windows; `SSL_CERT_FILE=$(python -c "import certifi;print(certifi.where())")` fixes it. A folder already installed makes it exit with "not empty", which reads like a failure but is fine.
- SKILL.md: `pre-commit` setup says to edit `CHECK=`; `sed -i` is blocked by the guard and a heredoc that writes source is too, so use the edit tool as stated. Inline `python - <<'E'` with backslash escapes is also blocked: write a scratch script.
- SKILL.md §Tools: a `strings` binary is not on Git Bash for Windows; use Python regex.
- references/graphics.md §Survey: dedupe on whole pixels: a first-256-bytes hash collapsed every texture with a blank top, and thin noise strips can be band-packed atlases (GE sprite vertices u, v, x, y, z in pairs) that must be composited before text is readable. Survey sheets at 1:1: 120-px thumbnails of 512-px atlases hide text.
- references/emulator-qa.md §PPSSPP: a game that printf()s Shift-JIS sends a non-UTF-8 WebSocket `log` event and `psp.py` `WS.recv` dies with UnicodeDecodeError; `tools/debug/gu.py` here swaps in a tolerant `json` shim, worth moving into `psp.py`. `cpu.setReg` takes `name=`, not `register=` with a name. Breakpoints work through `cpu.runUntilTime` with a loop on `cpu.stepping`.
- references/platform-psp.md: in a PRX, `lui`/`addiu` pairs naming .bss are relative to segment 1, not vaddrs: add the segment 1 load address. Reading the disassembly as vaddrs gives an address inside .text that accepts writes and does nothing visible.
- references/emulator-qa.md §Visual QA: `codex exec -i` is the fallback reviewer for Orca workers but can be over quota; sheets read in the main thread cost about 3k tokens each, so triage by id range and overview mosaics first.
- references/emulator-qa.md: PPSSPP input names are `ltrigger`/`rtrigger`, and a Game over-style forced flag can crash the game: read `ppsspp.log` in the run folder for the MIPS call stack when the websocket dies with EOFError.
- references/emulator-qa.md: `psp.Run` can raise `Target time has already passed` right after a state load; `tools/debug/gu.py` retries.
- references/emulator-qa.md: PPSSPPHeadless can also die with `ConnectionResetError` and nothing but its `--debugger` line in `ppsspp.log`, so no stack: seen forcing a screen that reads an empty party. Treat it as a guest fault, not a tool failure.
- references/emulator-qa.md §Debug tool: a menu row that "does nothing" may be an empty list: this game's Tutorial row waited on a list built from save bits that a warped run never set. Check the count before calling a row unreachable. Likewise a gated feature (skills here) can sit behind a story flag, so a warp must set it.
- SKILL.md ground rules: the guard hook blocks heredocs that write source, including an empty `python - <<EOF`; a stray `cat > /dev/null` in a command hangs until the Bash timeout.
- references/platform-psp.md: PGD (DATA.DNS form, drm_type 1) rebuilds byte-exact: table = one bbmac-with-vkey per encrypted block, 0x60 = MAC of table, 0x70/0x80 MACs of the header; plain bytes past data_size can be junk that must be kept for identity. See `tools/pgd.py` build().
- references/platform-psp.md: `cpk.py rebuild` refuses ITOC-only CPKs; a writer is about 60 lines (`tools/itoc.py` pack()): rows split into DataL/DataH at 0x10000, tables padded to 8. The game read formerly CRILAYLA files stored plain with no change, across 149 scenes.
- references/pipeline.md §Extract: a bytecode script walker with op+length becomes provable: "second byte > max instruction length" separates text from code, and spans covering every byte beat a pointer sweep as a coverage test. Read the handlers for ops that break the length rule (here return followed by tables, indexed gotos, strlen-sized inline strings).
- references/platform-psp.md: PRX relocations list every string reference: `R_MIPS_32` words and `lui`/`lo` pairs (val=1 relocs are .bss). Strings that look inline in .data with odd spacing were all pointed at; scan .data too, not only .rodata.
- references/platform-psp.md: Shift-JIS 0x90 lead bytes collide with 0x90 filler in game scripts; only pointers tell `90 ED` (戦) from padding.
- references/platform-psp.md: growing a plain PRX EBOOT: give the .bss-only segment file bytes (zeros) plus a blob, move the relocation segment back. PPSSPP applies the .rel SECTIONS when present, not the 0x700000A0 program header: new relocations must also extend the last .rel section, or they are silently skipped (code ran unrelocated, emulator died). See tools/eboot.py.
- references/platform-psp.md: keystone MIPS adds a delay-slot nop after every jump unless the source starts with `.set noreorder`; numeric local labels (1f/1b) return None.
- references/emulator-qa.md: a psp.Run probe script that never calls close() leaves PPSSPPHeadless running and holding the ISO; the next build then fails with PermissionError. End every probe with g.close() (try/finally).
- references/platform-psp.md: keystone (MIPS) sometimes assembles `jal <label>` as a `lw $t9,($gp); addiu; jalr $t9` PIC sequence, depending on earlier asm calls in the same Ks instance: new code built twice differed and one build crashed at boot. Use `bal label` for calls inside new code, and assert one instruction per source line.
- references/pipeline.md (Marker build): a marker longer than its Japanese can overflow a `sprintf` stack buffer and crash only the one screen that formats it (Gloria Union `%2d戦%2d勝`, 16 bytes); sweep every %-string's call for its buffer before the marker tour, and bisect with `--only` id prefixes when one scene dies.
- (any): a helper named after a stdlib module (`tools/debug/bisect.py`) shadows it for every script in that folder (`random` imports `bisect`); the warp died with ImportError and "no output".
- references/platform-psp.md: PTX-style loaders may rewrite the palette at load (Gloria Union: magenta entries get alpha 0). A new texture stored in its already-loaded form skips that, so keyed pixels draw opaque in every window that uses the texture's own CLUT; diff a loaded PTX in RAM against its file before building one.
- references/platform-psp.md (VWF): menus often place each cell themselves with a re-layout helper (absolute x, original column count, fixed pitch), which overrides a VWF x set at write time; fix it where sprites are built (chain a cell after its absolutely placed neighbour), not per menu.
- references/emulator-qa.md: PPSSPP websocket `memory.breakpoint.add` (write=True) on a cell found by a writer hook gives the code that edits it; a fixed address from a savestate is useless because the heap differs per boot.
- references/pipeline.md §Extract: glyph code tables, a fullwidth digit table and 0xFF-filled tables decode as Shift-JIS and are pointed at by code; extracting them as text let the marker build overwrite them (a font drew katakana for ASCII). Exclude strings with any 0xFF byte, and check every code-pointed "string" that is a run of consecutive codepoints.
- references/pipeline.md §Marker: after VWF, look for code that measures text in bytes (strlen / 2 x pitch to centre or right-align, strlen stored as a cell count, a layout loop that places only SJIS cells): it shows as text off-centre or cut at the left. Gloria Union had three such patterns.
- assets / keystone: `divu $a, $b` assembles to 3 instructions (zero check); write `divu $zero, $a, $b`.
- references/emulator-qa.md §Width gate: a fit ruler is laid out for one window's font; an entry drawn in several windows needs its shot taken in the window the ruler was made for, or label spacing looks scaled.
